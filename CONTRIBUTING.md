# Contributing

Submit a pull request adding a dataset or correcting its metadata. Include the original source URL/accession, category, reported sample unit and size, annotations, access conditions, explicit license evidence, version and review date. Record unknowns honestly. Check duplicates and cohort overlap. Link original hosts rather than uploading patient files. Keep CSV, JSON and README aligned. Place unconfirmed releases and supplementary-only records in docs/ADDITIONAL_LEADS.md until verified.
